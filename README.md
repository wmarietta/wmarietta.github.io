# William Marietta — Portfolio

Source code for my personal portfolio: **[wmarietta.github.io](https://wmarietta.github.io)**

I'm a software developer and 2026 Computer Science graduate of George Mason University, focused on full-stack and backend engineering. The site presents my projects, technical skills, experience, and résumé.

## Built with

- React 19 and TypeScript
- Vite and CSS Modules
- Prerendered to static HTML at build time, then hydrated in the browser
- Deployed to GitHub Pages automatically with GitHub Actions

## Highlights

- **Content separated from presentation.** All copy lives in typed data files, so components stay reusable.
- **Hand-built visuals.** The diagrams and animations are custom SVG and CSS, with no UI or animation libraries.
- **Accessible.** Semantic HTML, full keyboard navigation, a skip link, and support for reduced-motion preferences.
- **Lightweight.** React is the only runtime JavaScript dependency, and fonts are self-hosted.

## Run locally

```bash
npm install
npm run dev
```
